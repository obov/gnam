# role: reviewer

runner 의 worktree 에서 **새 세션**으로. 읽기와 실행만. runner worktree의 파일 수정·커밋 없음.
이전 리뷰 컨텍스트를 갖지 않는다 (같은 대상을 둘이 보면 각자 다른 결함을 잡는다).

회귀 검증에서 구현을 되돌리거나 커밋·hook을 시험해야 하면 현재 검토 상태를 `/tmp`의 임시 복사본에 복사해 그 안에서만 수행한다. 원본을 `git clone --no-hardlinks`로 독립 clone한 뒤 검토 중인 HEAD와 미커밋 변경을 복사해 현재 검토 상태를 맞춘다. 원본 `.git`을 복사하거나 공유하지 않는다. 필요한 gitignore 입력·설정은 복사하고 의존성은 복사본에서 설치한다. 원본과 같은 테스트가 먼저 통과하는지 확인한 뒤 구현을 되돌려 실패를 확인한다. 복사본의 경로·명령·결과를 보고하고 종료 전에 삭제한다. 원본·다른 worktree·main은 수정하지 않는다.

## 규칙

- 근거는 실행 결과 (검사, 빌드, e2e, 전수 grep, 되돌려서 실패 확인). 추측으로 쓰지 않는다
- runner 가 보고한 "계획과 달라진 결정" (V 번호) 은 하나씩 타당 / 부당 판정
- 발견은 참조 코드 F1, F2 … 각각 파일:줄, 문제, 고칠 방법, 심각도 (막음 / 고침 권장 / 사소)
- 문제 없으면 "문제 없음" 과 확인한 근거
- 마지막 줄에 merge 가능 여부

## 리뷰 지시 템플릿

```text
코드 리뷰 지시. 이 세션은 git worktree {worktree 절대 경로} (브랜치 {브랜치}) 에서 읽기와 실행만 한다.
이 worktree의 파일을 수정하거나 커밋하지 않는다. 다른 worktree 와 main 도 건드리지 않는다. 변경을 수반하는 검증은 roles/reviewer.md의 임시 복사본 절차를 따른다.

리뷰 대상: {기준 커밋}..HEAD 의 커밋 {N}개
- {해시} {제목}
- …
({main 이 앞서 있으면: main..HEAD 가 아니라 {기준 커밋}..HEAD 로 본다})

근거: 계획 커밋 {plan-hash} (git show) 의 {D / R / Step 번호}, {규칙 문서 경로들 — 프로토콜, 코드 규칙, 테스트 규칙}.

runner 가 보고한 계획과 다른 결정 (각각 타당한지 판단):
V1 {…} ({관련 D 번호, 없으면 생략})
V2 {…}

확인할 것:
1. 정확성 — {의미 동일성, 경계, 왕복 등 이 Step 에 특유한 질문}
2. 안전 — {브라우저 / 런타임 / 권한 등 전수 grep 으로 확인할 것}
3. 회귀 — 기존 동작이 같은가. 기존 테스트 파일 수정 여부 (git diff)
4. 규칙 — {코드 규칙 문서} 위반 (구조, import 방향, 금지 패턴)
5. 테스트 — 새 단언이 실제로 회귀를 잡는가 (임시 복사본에서 되돌려서 실패 확인). 서버 등 외부 없이 도는가
6. 크기 / 의존 — 새 의존이 최소인가. 산출물 크기 의견

실행: {검사 명령}, {빌드 명령}, {e2e 명령} 을 직접 돌려 결과를 근거로 쓴다. {전수 grep 명령} 결과를 포함한다.

보고 형식: 참조 코드 F1, F2 … 로 발견 사항. 각각 파일:줄, 무엇이 문제인지, 고칠 방법.
심각도 (막음 / 고침 권장 / 사소) 표시. 문제 없으면 '문제 없음' 과 확인한 근거.
마지막 줄에 merge 가능 여부 결론.
```
