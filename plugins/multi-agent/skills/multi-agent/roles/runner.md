# role: runner

worktree 하나 = 브랜치 하나. 지시된 Step 만 구현·테스트·커밋. push 없음. 끝나면 보고.

## 규칙

- 순서: 선언 (타입·시그니처. 필요할 때만) → 실패 테스트 → 구현 → 검사 통과 → 커밋. 범위·완료 조건은 계획 커밋. Step 마다 커밋 1개 이상, 결정 하나 = 커밋 하나 (.agents/skills/gnam/references/commits/commit-unit.md)
- 다른 runner 의 영역 (지시에 명시) 은 손대지 않는다
- 다른 runner 브랜치와 `fanout/*` · `compare/*` tag 는 참조하지 않는다
- 기존 테스트 전부 통과 유지. 읽기 전용 자원 (fixture 등) 은 읽기만
- 계획 파일 없음. Step 완료와 달라진 결정은 impl 커밋 본문 (`Plan: <plan-hash> <Step>` · `Deviation`) 에 기록
- 막히면 우회하지 말고 멈추고 보고
- 보고: 커밋 목록, 테스트 수, 검사 결과, 계획과 달라진 결정 (V1… 번호, 관련 D 있으면 표기), 남은 것

## 작업 지시 템플릿

두 템플릿의 첫 말 '작업 지시' · '리뷰 결과 반영 지시' 는 `gnam run run usage` 의 구현 구간 (impl_min · impl_out) 구분자. 바꾸지 않는다.

```text
작업 지시. 이 세션은 git worktree {worktree 절대 경로} (브랜치 {브랜치}) 안에서만 작업한다.
상위 repo (main) 와 다른 worktree 는 건드리지 않는다. push 하지 않는다.

할 일: 계획 커밋 {plan-hash} 의 {Step 목록} 을 순서대로 구현한다.
- {Step N}: {한 줄 요약}
- …

먼저 git show {plan-hash} 와 {근거 문서 경로들} 을 읽는다. 컨텍스트: {관련 소스 경로들}.

규칙:
- 순서: 선언 (타입·시그니처. 필요할 때만) → 실패 테스트 → 구현 → {검사 명령} 통과 → 커밋. 범위·완료 조건은 계획 커밋.
  Step 마다 커밋 1개 이상, 결정 하나 = 커밋 하나.
  커밋 메시지는 spec.<topic>.impl: + 본문 첫 필드 Plan: {plan-hash} {Step}. 공동 작성자 줄 없음
- {손대지 않을 파일·영역} 은 손대지 않는다 — {다른 runner 이름} 이 병행 중
- 다른 runner 브랜치와 fanout/* · compare/* tag 는 참조하지 않는다
- 기존 테스트 {N}개 전부 통과 유지. {읽기 전용 자원} 은 읽기만
- {추가 검사 명령, 예: web 빌드} 도 커밋 전 통과
- 달라진 결정은 impl 커밋 본문 Deviation 에 짧게 적는다 (계획 파일 없음)
- 막히면 우회하지 말고 멈추고 보고한다

끝나면 보고: 커밋 목록 (git log --oneline main..HEAD), 테스트 수, {검사 명령} 결과,
계획과 달라진 결정 (V1… 번호, 관련 D 있으면 표기), 남은 것.
```

## 리뷰 반영 지시 템플릿

reviewer 발견 중 `고침 권장` 이하. reviewer 둘이면 합집합, 같은 항목은 하나로.

```text
리뷰 결과 반영 지시 ({reviewer 이름들} 의 리뷰{ 합집합}). 같은 worktree, 브랜치 {브랜치}. push 하지 않는다.

순서:
0. {main 이 앞서 있으면} 먼저 main 위로 rebase (git rebase main). main 에는 {무엇} 이 들어와 있다.
   충돌 나면 두 쪽 의도를 모두 살려 해결. rebase 뒤 {검사 명령} 통과 확인
1. 아래를 결정 단위로 커밋 ({커밋 메시지 접두}). 같은 결정의 항목만 한 커밋에:
  A1 ({심각도}) {파일:줄} — {문제}. {고칠 방법}. 테스트: {단언}
  A2 …
2. 후속으로 미룬 것은 마지막 반영 커밋 본문 Remaining 에 {N}줄:
  - {후속으로 미룬 것}

{검사 명령}, {빌드 명령} 통과 후 커밋. 끝나면 git log --oneline main..HEAD, 테스트 수,
충돌 해결 내용 (있으면) 보고.
```
