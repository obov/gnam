# s3 — 첨부 보관

git 에는 첨부 줄 (이름 · sha256 · 위치) 만, 파일 내용은 S3 호환 저장소에. 같은 내용은 한 번만 올라간다 (key = `<prefix><sha256>`).
요구사항 원본: `specs/s3.md` (gnam 저장소).

## 설정

```json
{ "s3": { "endpoint": "https://<account>.r2.cloudflarestorage.com", "bucket": "gnam", "region": "auto" } }
```

```text
endpoint    필수. https (http 는 localhost 만)
bucket      필수
region      기본 us-east-1. R2 = auto
prefix      기본 gnam/
pathStyle   기본 true. AWS S3 virtual-host 를 쓰려면 false
maxBytes    기본 100MB
```

자격은 환경 변수만 (gnam.json 에 넣으면 검사 오류):

```bash
export GNAM_S3_ACCESS_KEY_ID=…  GNAM_S3_SECRET_ACCESS_KEY=…   # 없으면 AWS_ACCESS_KEY_ID · AWS_SECRET_ACCESS_KEY
```

## 요청에 첨부가 있을 때

```text
1. 저장소 밖 파일마다      npx gnam run s3 put <파일>
2. 출력 줄                 request 커밋 Attachments: 에 그대로 붙인다
3. 실패 (설정 · 자격 · 네트워크)  위치 '없음' + ← <원래 경로> 로 기록하고 사용자에게 한 줄 알린다
```

저장소 안 파일은 올리지 않는다 (`<경로>@<커밋>`).

## 다시 꺼낼 때

```bash
npx gnam run s3 get sha256:<hex> -o /tmp/x.png    # 내용 sha256 확인 후 저장
npx gnam run s3 url sha256:<hex> --expires 3600   # 브라우저 · 사용자 공유용 임시 링크 (만료 전까지 누구나 열람)
npx gnam run s3 check                             # 기록된 s3 첨부가 전부 있는지
```
